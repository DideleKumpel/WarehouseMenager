Description This is a simple desktop application for managing an industrial warehouse. It provides functionality tailored for managers and employees. The program uses WPF (Windows Presentation Foundation) for the frontend and C# for the backend. It connects to a database to manage user authentication and task operations efficiently.

Features User Authentication The application starts with a login screen that verifies user credentials and determines the type of user account: Manager or Employee.

Manager Panel Managers can: Monitor tasks Add, edit, and delete tasks View task details retrieved from the database

Employee Panel Employees can: View a list of tasks assigned to the warehouse Assign tasks to themselves Mark tasks as completed

Technology Stack Frontend: WPF (Windows Presentation Foundation) Backend: C# Database: MySql
